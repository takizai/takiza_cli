# Ревайнд: GUI и CLI

Сравнение с локальной GUI-версией в `~/takiza-gui` на 26 октября 2026 года.
Источник: `src-tauri/src/core/checkpoints.rs`, `core/session.rs`,
`commands.rs` и `src/stores/agentStore.ts` в GUI-проекте.

| Поведение | GUI | CLI после адаптации |
|---|---|---|
| Точка перед запросом модели | Да | Да; Plan не создаёт файловые снимки |
| Остановка активного ответа и очистка очереди перед откатом | Да | Да |
| Предпросмотр и отдельное подтверждение | Да | Да; по умолчанию выбран отказ |
| Резервная точка перед откатом, отмена отката | Файлы и чат | Файлы и чат |
| Восстановление состояния сессии | Сессия целиком | Сообщения, история, название, модель в метаданных, контекст и дополнительные поля; накопленный расход токенов сохраняется |
| Состояние агента после отката | Сброс агента и установка сообщений | Сброс агента, подагентов и LSP-документов, установка сообщений; выбранное подключение сохраняется |
| Выполнение операций хранения | `spawn_blocking`, признак занятости | `spawn_blocking`, индикатор в терминале без записи в историю |
| Исходный запрос после отката | Не возвращается в поле ввода | Возвращается целиком для редактирования, без автоматической отправки |
| Хранение файлов | Полные копии, hardlink внутри чата | Неизменённые байты из коммита — ссылки на Git-объекты; локальные копии — hardlink между чатами |
| Хранение переписки | Полная копия в каждой точке | Общие сжатые архивы сообщений и элементов истории |
| Ограничение времени создания точки | 10 секунд | До завершения или явной отмены |
| Удаление чата | Файлы сессии | Сессия, её точки, архивы переписки и служебные Git-ссылки |

CLI сохраняет накопленный расход токенов: откат разговора не отменяет уже
выполненные запросы к провайдеру. Размер контекста при этом возвращается к
состоянию выбранной точки. Незавершённая генерация названия чата отменяется,
чтобы название из более позднего состояния не перезаписало восстановленное.

CLI читает файловые точки GUI формата 1, включая сессии с дополнительными
полями GUI. Проверка в терминале покрывает импорт такой точки, предпросмотр,
откат файлов и сессии, восстановление исходного запроса и отмену отката.

Это не двусторонняя совместимость: текущая GUI читает только формат 1,
а CLI записывает форматы 2–3 и при сохранении может переводить старые точки
в сжатое хранилище. Для использования одной истории обоими приложениями
нужна отдельная поддержка новых форматов в GUI. GUI-проект не изменялся.
